# Builderlab decisions

Answers the app's decisions with your Builderlab account, instead of a
TypeSafe key. Attention uses decisions to check which events should wake an
agent.

## Getting started

1. Turn on this plugin. It also needs the **Builderlab** plugin, which is on
   by default.
2. Open **Settings > Decisions API** and select **Builderlab**.
3. Sign in with Builderlab, if you are not signed in.

Builderlab answers only for accounts it has turned decisions on for. Until you
select Builderlab, TypeSafe keeps answering. Decision text can include private
messages, so Buzz never moves it to Builderlab without your choice.
